Installation facultative

L’installation ajoute un raccourci à l’écran d’accueil. Elle n’est pas nécessaire pour enregistrer vos entrées : la sauvegarde automatique est déjà active.

Android : ouvrez ce lien dans Chrome, puis menu ⋮ → « Installer l’application » ou « Ajouter à l’écran d’accueil ». PC : cliquez sur l’icône d’installation dans la barre d’adresse, ou ouvrez le menu Chrome/Edge → « Installer Mon planning » / « Installer ce site en tant qu’application ». Cette installation ajoute un raccourci ; la sauvegarde automatique et l’export JSON restent distincts.

Premier chargement avec Internet. Les outils OCR/HEIC peuvent aussi nécessiter une connexion ; les photos ne sont pas envoyées.
